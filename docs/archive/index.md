# Archive

The pages in this section are handover notes and runbook evidence written
during specific milestones of Spawnery's development. Each one was accurate
on the date it was written.

None of them has been maintained since. Commands, paths, versions and cluster
states described here may no longer match the current codebase or any live
deployment.

For documentation that is kept up to date, see [Guides](../guides/upgrading.md)
and [Reference](../reference/known-issues.md).
