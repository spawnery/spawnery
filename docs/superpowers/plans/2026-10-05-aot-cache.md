# JVM Startup Cache Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Purpur servers start from a JDK AOT cache trained per image, so the JVM no longer loads and links Minecraft's classes from scratch on every start. The Paper image, deprecated since 0.2.15, is no longer built.

**Architecture:** The Purpur images start the server flat (`java -cp <class path> <main>`) from launch files the nix build derives from the bundler's manifests, so Minecraft's classes load through the application class loader. The release trains each Purpur image once and publishes the cache as `ghcr.io/spawnery/purpur-aot:<tag>`. With `--aot-cache` on, the operator mounts that image as an image volume at `/var/run/spawnery/aot`, and the entrypoint passes `-XX:AOTCache` when the file is there.

**Tech Stack:** POSIX sh (entrypoint), bash (hack scripts), nix, Go (operator), Helm chart, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-05-aot-cache-design.md`

## Global Constraints

- Every command runs from the repository root. `ND` below stands for `nix --extra-experimental-features 'nix-command flakes' develop . -c`.
- Before a heavy run, `hostname`: on `dev` (the development VM), envtest packages run with `-p 1`; on `paul-desktop` without.
- `CONTAINER=podman` on both machines (`docker` there is podman's shim or absent).
- The game images stay bit-for-bit reproducible: `make image-repro` passes at the end of Task 2. Training output never enters a nix derivation.
- Every environment variable the entrypoint reads is `SPAWNERY_`-prefixed and read as `${NAME:-default}` (`image/reserved_env_test.go`).
- Cache image name: `ghcr.io/spawnery/purpur-aot`, same tag as the Purpur image, one file `/server.aot`, mode 0444. No Paper cache: the Paper image is retired in Task 1.
- Mount path in the pod: `/var/run/spawnery/aot`; file the entrypoint looks for: `/var/run/spawnery/aot/server.aot`.
- Operator: mapping only for `ghcr.io/spawnery/purpur`, tag `<mc>-<x.y.z>` with `x.y.z >= 0.23.0`. Everything else, `ghcr.io/spawnery/paper` included, gets no volume.
- Published `ghcr.io/spawnery/paper` tags stay on the registry; only new ones stop.
- Version bumps (imageVersion 0.23.0, operator and chart minor) are not part of this plan; they go in the release PR.
- New files carry the `Copyright paul_wtf.` header where the neighbours do (Go files).
- Commits: Conventional Commits, gpg-signed; run `echo probe | gpg --clearsign --pinentry-mode error -u "$(git config user.signingkey)" > /dev/null` before the first commit of a session and ask Paul to unlock on a non-zero exit.

## Review Focus

1. **A cache image that is not pullable** (the release failed between pushes, or the new `purpur-aot` package on ghcr.io is still private): with `--aot-cache` on, the image volume cannot be pulled and the server pod never starts. Expected: the release pushes the cache before the game image, so a published game tag always has its cache; the first publish needs the package switched to public by hand. Task 5 pins the push order.
2. **Image references that must not get a cache:** a digest without a tag, a mirror registry, `paper`, `velocity`, `purpur-aot` itself, tags without a version, versions below 0.23.0, prerelease-shaped versions. Expected: no volume, server starts as today. Task 6's table test.
3. **A runtime heap different from the training heap** (groups with 3, 6 or 12 GiB limits): the cache must still map. Task 4's image test trains under one memory limit and runs under another.
4. **A group whose `JAVA_TOOL_OPTIONS` changes a flag the cache depends on** (for example `-XX:-UseCompressedOops`): expected a JVM warning and a normal start without the cache, never a failed start. Task 4's image test runs that case.
5. **A training run that never reaches `Done` or writes no cache:** the release must stop with the log, not publish an empty or missing cache. Task 4's `hack/aot-train-test.sh`.

```nix
# The class path and main class the bundler would use, read from its own
# manifests, so the entrypoint can start the server without the bundler. The
# server jar from versions/ comes first: behind the libraries, Mojang's logging
# library shadows the server's patched LogUtils (NoSuchMethodError).
{ runCommand, unzip }:

{ name, serverJar, repo, home }:

runCommand "${name}-launch" { nativeBuildInputs = [ unzip ]; } ''
  mkdir -p $out${home}
  : > entries
  for dir in versions libraries; do
    unzip -p ${serverJar} META-INF/$dir.list > $dir.list
    while IFS=$'\t' read -r _ _ path; do
      if [ ! -f "${repo}/$dir/$path" ]; then
        echo "META-INF/$dir.list names $path, which ${repo}/$dir does not carry" >&2
        exit 1
      fi
      echo "${home}/repo/$dir/$path" >> entries
    done < $dir.list
  done
  paste -sd: entries > $out${home}/launch.classpath
  unzip -p ${serverJar} META-INF/main-class > $out${home}/launch.main
  test -s $out${home}/launch.main
  chmod -R a-w $out${home}
''
```

### Task 3: AOT flags in the entrypoint

**Files:**
- Modify: `image/entrypoint.sh`
- Test: `image/entrypoint_test.go`

**Interfaces:**
- Consumes: Task 2's flat `exec java … -cp … <main> --nogui`.
- Produces: `SPAWNERY_AOT_CACHE` (default `/var/run/spawnery/aot/server.aot`): when that file exists, `-XX:AOTCache=<file>` before `-cp`. `SPAWNERY_AOT_OUTPUT=<file>`: `-XX:AOTCacheOutput=<file>` instead, for training; it wins over a mounted cache and drops `-XX:+AlwaysPreTouch`.

The JVM builds the cache in a child process that inherits every flag, while the training JVM still holds its heap. With `AlwaysPreTouch` both claim three quarters of the memory limit, and the child is OOM-killed (measured 2026-10-05: exit 137 under 2 GiB; under 4 GiB without pre-touch the cache was written).

```bash
#!/usr/bin/env bash
# Trains the JVM's AOT cache for a Purpur image and leaves it in
# OUT/server.aot. The image's own entrypoint runs the training, so the cache
# carries exactly the flags every server starts with.
#
# The first boot only creates the world; the training boot loads it, as a
# server with a world does. Training on world creation pushes the JDK's
# MethodType table past the 256 KiB the cache can hold for one object, and the
# cache step fails. 4 GiB: the training JVM and the child that writes the
# cache run side by side.
set -euo pipefail

CONTAINER="${CONTAINER:-docker}"
IMAGE="${IMAGE:?IMAGE must be set}"
OUT="${OUT:?OUT must be set}"
DEADLINE="${DEADLINE:-300}"

NAME="spawnery-aot-train-$$"
VOLUME="spawnery-aot-train-$$"
WORK="$(mktemp -d)"
cleanup() {
	"$CONTAINER" rm -f "$NAME" >/dev/null 2>&1 || true
	"$CONTAINER" volume rm -f "$VOLUME" >/dev/null 2>&1 || true
	rm -rf "$WORK"
}
trap cleanup EXIT

mkdir -p "$WORK/conf/overlay" "$WORK/out"
printf 'maxPlayers: 1\n' >"$WORK/conf/config.yaml"
printf 'aot-training\n' >"$WORK/conf/forwarding.secret"
printf 'level-type=minecraft\\:flat\ngenerate-structures=false\nview-distance=4\n' \
	>"$WORK/conf/overlay/server.properties"
chmod -R a+rX "$WORK/conf"
# The container writes as uid 10001.
chmod 777 "$WORK/out"
"$CONTAINER" volume create "$VOLUME" >/dev/null

# boot LABEL [ENV...] starts the server, sends "stop" once it is Done (or the
# deadline passed, or the container is gone), and returns once it exited.
boot() {
	local label="$1"
	shift
	local log="$WORK/$label.log"
	: >"$log"
	local env=()
	for e in "$@"; do env+=(-e "$e"); done
	(
		start=$SECONDS
		seen=0
		while :; do
			if grep -q 'Done (' "$log"; then
				: >"$WORK/$label.done"
				break
			fi
			if "$CONTAINER" container inspect "$NAME" >/dev/null 2>&1; then
				seen=1
			elif [ "$seen" = 1 ]; then
				break
			fi
			[ $((SECONDS - start)) -gt "$DEADLINE" ] && break
			sleep 1
		done
		echo stop
	) | "$CONTAINER" run -i --rm --name "$NAME" \
		--network none \
		--read-only --tmpfs /tmp:rw,exec,size=256m \
		--cap-drop ALL \
		--security-opt no-new-privileges \
		--memory 4g \
		-v "$VOLUME:/data" \
		-v "$WORK/conf:/etc/spawnery:ro" \
		-v "$WORK/out:/var/run/spawnery/aot-out" \
		"${env[@]}" \
		"$IMAGE" >"$log" 2>&1 || true
	# The marker, not the log: a "stop" sent at the deadline still lets a slow
	# server print Done before it stops.
	if [ ! -e "$WORK/$label.done" ]; then
		echo "the $label boot never reached Done within ${DEADLINE}s:" >&2
		tail -40 "$log" >&2
		exit 1
	fi
}

boot world
boot training SPAWNERY_AOT_OUTPUT=/var/run/spawnery/aot-out/server.aot

if [ ! -s "$WORK/out/server.aot" ]; then
	echo "the training boot reached Done but wrote no cache:" >&2
	grep -E '\[error|Child process' "$WORK/training.log" | tail -20 >&2 || tail -40 "$WORK/training.log" >&2
	exit 1
fi
mkdir -p "$OUT"
cp "$WORK/out/server.aot" "$OUT/server.aot"
chmod 0444 "$OUT/server.aot"
echo "trained $(du -h "$OUT/server.aot" | cut -f1) for $IMAGE"
```

```go
package podspec

import (
	"strconv"
	"strings"

	corev1 "k8s.io/api/core/v1"
)

const (
	AOTCacheVolumeName = "aot-cache"
	// AOTCacheMountPath is where image/entrypoint.sh looks for server.aot.
	AOTCacheMountPath = "/var/run/spawnery/aot"
)

// aotCacheSince is the first image version released with a cache image beside
// each game image; an older tag has none to pull.
var aotCacheSince = [3]int{0, 23, 0}

const aotCacheRepository = "ghcr.io/spawnery/purpur"

// AOTCacheImage names the startup cache published with spawnery's Purpur
// image, or returns "" for any image that has none. A digest is dropped
// and the tag kept: the release publishes the cache by tag.
func AOTCacheImage(image string) string {
	ref, _, _ := strings.Cut(image, "@")
	colon := strings.LastIndex(ref, ":")
	if colon < 0 || colon < strings.LastIndex(ref, "/") {
		return ""
	}
	repository, tag := ref[:colon], ref[colon+1:]
	if repository != aotCacheRepository {
		return ""
	}
	_, version, ok := strings.Cut(tag, "-")
	if !ok || !atLeast(version, aotCacheSince) {
		return ""
	}
	return repository + "-aot:" + tag
}

func atLeast(version string, floor [3]int) bool {
	parts := strings.Split(version, ".")
	if len(parts) != 3 {
		return false
	}
	var got [3]int
	for i, p := range parts {
		n, err := strconv.Atoi(p)
		if err != nil || n < 0 {
			return false
		}
		got[i] = n
	}
	for i := range got {
		if got[i] != floor[i] {
			return got[i] > floor[i]
		}
	}
	return true
}

// WithAOTCache mounts the startup cache of the pod's game image, if it has one.
func WithAOTCache(pod *corev1.Pod) {
	for i := range pod.Spec.Containers {
		c := &pod.Spec.Containers[i]
		if c.Name != ContainerName {
			continue
		}
		cache := AOTCacheImage(c.Image)
		if cache == "" {
			return
		}
		pod.Spec.Volumes = append(pod.Spec.Volumes, corev1.Volume{
			Name: AOTCacheVolumeName,
			VolumeSource: corev1.VolumeSource{
				Image: &corev1.ImageVolumeSource{Reference: cache, PullPolicy: corev1.PullIfNotPresent},
			},
		})
		c.VolumeMounts = append(c.VolumeMounts, corev1.VolumeMount{
			Name:      AOTCacheVolumeName,
			MountPath: AOTCacheMountPath,
			ReadOnly:  true,
		})
		return
	}
}
```
